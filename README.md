# Haven - Caring Companion for Patients & Seniors

Haven is a compassionate, accessible web application designed to support seniors and patients living with dementia, Alzheimer's, Parkinson's disease, post-stroke recovery (aphasia), and mild cognitive impairment (MCI).

## 🌟 Key Features

- **My Day & Reminders**: High-contrast, easy-to-read schedule with clear one-tap actions for taking medicines and tracking daily wellness.
- **Adaptive Care Hub**:
  - **Parkinson's Disease**: Motor timing, punctual medication reminders, hydration counter, and 2-minute gentle stretches.
  - **Post-Stroke & Aphasia**: One-tap visual speech board with audio read-aloud via the Web Speech API.
  - **Mild Cognitive Impairment (MCI)**: Clear, manageable daily checklists and cognitive games.
  - **Senior Living & Connection**: Speed-dial family, "Send Love" heart button, and warm daily affirmations.
  - **Dementia & Memory Care**: Reassuring daily messages and familiar photo prompts.
- **Therapeutic Mini-Games**:
  - *Picture Matching* (Memory)
  - *Familiar Faces* (Social Recognition)
  - *Steady Rhythm Tap* (Motor Control)
  - *Peaceful Bubble Catch* (Coordination & Touch)
  - *Word & Object Connect* (Speech Recovery)
  - *Sentence Companion* (Language Flow)
  - *Daily Item Sorting* (Focus & Organization)
  - *Morning Routine Order* (Daily Sequencing)
  - *Zen Flower Bloom* (Relaxation & Joy)
  - *Serene Breathing Circle* (Mindful Calming)
- **Cherished Memories**: Photo albums with voice narration that reads memory stories aloud to the patient.
- **Loved Ones Directory**: Large portrait cards with one-tap calling and spoken descriptions.
- **Accessibility First**:
  - 4-level dynamic text scaling (A− / A+)
  - Multi-language support (English, Hindi, Bengali, Assamese, Spanish, French, Chinese)
  - High-contrast colors and tremor-friendly touch targets
  - Built-in resilient offline/demo mode

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Internationalization**: i18next & react-i18next
- **Audio & Speech**: Web Speech API & Web Audio Synthesizer

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
